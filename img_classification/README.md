# img_classification

## Overview

This repository contains the source code to implement an image classification system using Convolutional Neural Networks and transfer learning to classify images of animals into various categories.

The end goal of this project is to put into practice some Deep Learning concepts such as:
- CNN architectures.
- Transfer learning.
- Optimization.
- Data augmentation.
- Overfitting and regularization.

## Problem overview

Given an input image, the model predicts the animal class (e.g., dog, cat, bird, fish, etc).
This is a multi-class classification problem.
